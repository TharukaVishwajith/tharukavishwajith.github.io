# tharuka.xyz

Personal site of Tharuka Sarathchandra, plus **Wizard Lab**, a learning hub for software engineering, AI and data series.

Built with Jekyll and served by GitHub Pages; there's no server and no build step to run yourself.

| Path | What it is |
|------|------------|
| `index.html` | Home page. Content comes from `_data/experience.yml`, `_data/projects.yml`, `_data/skills.yml`. |
| `learn/` | Learning hub pages (home, all articles, series pages). |
| `_articles/` | Articles, written in Markdown. |
| `_data/series.yml` | The list of series. |
| `assets/` | CSS and JS (no frameworks). |
| `docs/` | How to write articles and set up `learn.tharuka.xyz`. Not published. |

- To add an article, see [docs/writing-articles.md](docs/writing-articles.md).
- To put the hub on a subdomain, see [docs/subdomain-setup.md](docs/subdomain-setup.md).
