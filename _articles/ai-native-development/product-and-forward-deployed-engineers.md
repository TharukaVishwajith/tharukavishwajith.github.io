AI Coding Agents නිසා අද Code ලියන එක වෙනදාට වඩා වේගවත් වෙලා තියෙනවා.

නමුත් Code Generate කරන වේගය වැඩි වුණා කියලා, ඒ වේගයෙන්ම Software Production එකට Deliver කරන්න පුළුවන්ද?

## Bottleneck එක මාරු වෙන ආකාරය

මෙතැනදී තමයි **Bottleneck** කියන සංකල්පය වැදගත් වෙන්නේ.

කලින් Code ලියන්න වැඩි කාලයක් ගත වුණා. අද Code Generation වේගවත් වෙනකොට Bottleneck එක Code Review, Testing සහ Deployment වගේ පියවරවලට මාරු වෙනවා.

හෙට ඒවාත් Automate වුණොත්?

ඊළඟ Bottleneck එක වෙන්නේ සැබෑ Business Problem එක හඳුනාගැනීම සහ සාර්ථක විසඳුමක් කියන්නේ මොකක්ද කියලා තීරණය කිරීම වෙන්න පුළුවන්.

මෙතැනදී වැදගත් වෙන Engineering Roles දෙකක් තියෙනවා.

## 1. Product Engineer

Users ලාගේ සැබෑ අවශ්‍යතා තේරුම් ගන්න, Product Decisions ගන්න, Success Criteria නිර්වචනය කරන්න සහ AI Agents භාවිතයෙන් Solutions Deliver කරන්න පුළුවන් Engineer කෙනෙක්.

## 2. Forward Deployed Engineer (FDE)

Customer එක්ක සෘජුව වැඩ කරමින් ඔවුන්ගේ Business Workflows සහ ගැටලු හඳුනාගෙන, ඒ පරිසරයට ගැළපෙන Technical Solutions නිර්මාණය කරලා Deploy කරන Engineer කෙනෙක්.

මේ Roles අලුත්ම සංකල්ප නොවුණත්, AI යුගයේ ඒවාට ලැබෙන අවධානය සහ වැදගත්කම වැඩි වෙමින් තියෙනවා.

## Education System එක වෙනස් වෙන්න ඕනද?

අදත් අපි බොහෝ Junior Developers ලා පුහුණු කරන්නේ Programming Languages, Frameworks සහ හොඳින් නිර්වචනය කළ Tasks විසඳන්නයි.

ඒ දැනුම වැදගත්. නමුත් ඒක විතරක් ප්‍රමාණවත් නැහැ.

අපි අලුත් පරම්පරාවට **Problem Discovery**, **Product Thinking**, **Requirement Engineering** සහ **AI Agent Orchestration** වගේ Skills ප්‍රායෝගිකව උගන්වන්න ඕන.

උදාහරණයක් විදිහට, තවත් CRUD Application එකක් හදනවා වෙනුවට, සැබෑ Business එකක ගැටලුවක් හඳුනාගෙන, Requirements Define කරලා, AI භාවිතයෙන් Solution එකක් Deliver කරන Project එකක් දෙන්න පුළුවන්.

## මගේ අදහස

අනාගතයේ වටිනාකම වැඩි වෙන්නේ Code Generate කරන වේගයට පමණක් නෙවෙයි. නිවැරදි Problem එක හඳුනාගෙන, නිවැරදි Solution එක Deliver කිරීමේ හැකියාවටයි.

ඒ නිසා අපි AI Tools භාවිත කරන්න දන්න Developers ලා විතරක් නොවෙයි, සැබෑ ලෝකයේ ගැටලු විසඳන්න පුළුවන් **Next-Generation Engineers** ලා බිහි කරන්න අවධානය යොමු කළ යුතුයි.
